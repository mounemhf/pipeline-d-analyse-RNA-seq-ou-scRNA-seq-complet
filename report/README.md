# Report

The final analysis report (`report.md`) is **generated by the pipeline**
(`workflow/rules/report.smk`). The latest generated report is committed as
the showcase deliverable.

It embeds the publication-quality figures from `results/figures/` and a
written biological interpretation of the PBMC populations identified and
their marker genes. Regenerate it from the repository root with:

```bash
snakemake --use-conda --cores 4
```
