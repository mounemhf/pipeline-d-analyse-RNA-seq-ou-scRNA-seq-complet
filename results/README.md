# Results

Everything in this directory is **generated by the pipeline**. Only the final
figures (`figures/*.png`) are tracked by git, as the portfolio showcase; all
other outputs are regenerated on demand from the repository root with:

```bash
snakemake --use-conda --cores 4
```

Expected layout after a full run:

```
results/
├── figures/   # publication-quality figures (300 dpi PNG)
├── tables/    # marker genes, cluster summaries, annotation tables (CSV/TSV)
├── qc/        # FastQC / MultiQC reports
├── processed/ # AnnData objects (.h5ad) at each analysis stage
└── logs/      # one log file per rule execution
```
